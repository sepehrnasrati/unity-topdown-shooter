# Arcane Slime Seige (Unity)

A 2D twin-stick shooter prototype built in Unity (C#) featuring multiple levels, wave-based enemy spawning, and incremental difficulty.

## Features
- Player movement, aiming, and shooting
- Modular health/damage and collision handling
- Multiple levels with increasing difficulty
- Wave-based enemy spawning and a final challenge level
- Enemy AI behaviour using state-based logic

## Tech Stack
- Unity
- C#

## How to Run
1. Clone the repository
2. Open the project in Unity Hub
3. Press Play
